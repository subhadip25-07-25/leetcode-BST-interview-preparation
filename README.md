The repository is maintained as a problem-solving and interview-revision resource. Individual problem folders contain the corresponding solution and LeetHub-generated problem notes.

## Concepts and patterns covered

- **BST fundamentals:** search, insertion, validation, trimming, and range-based pruning.
- **Inorder traversal:** sorted order, kth smallest, mode, minimum difference, and recovering swapped nodes.
- **Reverse inorder:** transforming a BST into a greater-sum tree.
- **Tree construction:** building balanced BSTs from sorted arrays/lists and constructing from preorder.
- **BST properties:** lowest common ancestor, predecessor/successor-style queries, and closest values.
- **Search techniques:** hash map lookup and combining values from two BSTs.
- **Balanced trees and Catalan DP:** balancing a BST and counting/generating unique BSTs.
- **Tree DP:** maximum-sum BST inside a binary tree.
